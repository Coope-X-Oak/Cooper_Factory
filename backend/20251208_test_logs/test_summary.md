# 测试执行日志 - 2025-12-08

## 概览
Bilibili 字幕抓取服务优化 (重构与健壮性提升)

## 变更摘要
1.  **架构解耦**: 将 `subtitle_service.py` 从 `bili_service.py` 中拆分，实现独立测试与维护。
2.  **策略升级**: 实现了多级降级策略 (API -> Cookie) 和多候选优先排序 (人工/中文 > AI/其他)。
3.  **核心修复**:
    *   **反爬避障**: 在 `_get_cid_and_title` 中增加 BVID 强校验，防止因 B站反爬虫机制重定向到“热门视频”而导致的数据串台。
    *   **重试机制**: 对元数据获取增加 3 次重试，应对网络波动。
    *   **规则精简**: 移除了不稳定的“内容关键词校验” (Bigram)，避免因标题过长或口语化导致的误杀。
